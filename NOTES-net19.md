# NOTES-net19: enlace, personaje "solo", nombre, cinematicas

1. Enlace `#sala=`: main.js `openLink()` -> `UI.joinCode(Net.codeFromHash())` (pide nombre y une). Codigo invalido: toast "Enlace de sala no valido" + menu. `hashchange`: si ya hay partida/sala solo avisa; si no, une. Tras unirse ui.js limpia el hash (`replaceState`).
2. Personaje que se movia solo (causas reales, en el host): (a) el input remoto quedaba retenido al cambiar de fase (el host solo lo ponia a ZERO al llegar otro mensaje; ademas el motor restaura `rawIn` al acabar la cinematica de viaje); (b) el cliente solo enviaba input en eventos de teclado (sin latido). Arreglo: `setupBots` no deja bot a un rol con dueno humano y lo inicia en ZERO; el host pone ZERO a los remotos en cada `advance()`; el cliente reenvia su estado cada 200 ms y al cambiar de fase, y suelta teclas en `blur`/`visibilitychange`; el host pone ZERO si pasan 1.5 s sin `input` de un remoto (tecla pegada / pestana dormida). El input de un rol que no es de ese dueno (p. ej. el rol del host) se ignora.
3. Nombre: `UI.askName()` modal "¿Como te llamas?" (max 14, Enter, recordado en `rcv3_name`, vacio -> "Jugador N") antes de Crear sala / Unirse / enlace. `Net.cleanName` (quita control y `<>&"'\`\\`, max 14) se aplica al enviar y al recibir (host en uniones/hello, cliente en el roster `players`). Lobby: "Nombre · Rol". Host: toast "X se unio"/"X se fue" (main.js). Chat: cabecera `Rol · Nombre` (st.players[r].pname, hud.js, escapado).
4. Cinematicas: solo el host salta. `playCinematic`/`playEnding`: cliente ve el boton desactivado "Solo el anfitrion salta" y Esc no hace nada; el host emite `cineskip` -> `Net.broadcast('cine',{act:'skip'})` -> clientes `UI.skipCine()`. Si no llega, la cinematica acaba sola por duracion (el final de `playEnding` sigue pidiendo clic local). Viaje del motor: ya era solo-autoridad (`skipCutscene`/Esc/"ESPACIO: SALTAR" solo con authority); touch.js oculta SALTAR » en clientes. Dialogos Hud: cada cliente cierra el suyo y solo el host avanza fase; sin cambios.
