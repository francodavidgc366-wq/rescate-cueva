# NOTES-ui3 (agente UI-A) - src/ui.js -> `window.UI` (v3, reescrito)
Pantallas fuera de partida. Sin audio propio (usa `window.Sound` con guardas: sfx/music/unlock/speak/stopSpeak/setVol/mute). Arte via `ASSETS.*` con fallback procedural. Prueba: `tools/ui-test.html` (`?real=1` carga assets.js real; `?go=menu|tutorial|lobby|lobbyhost|intro|rescate|derrota|role|final|finalD|ach|settings|credits`; `dev0=1` oculta la barra; Sound/Net stubs; log de sfx arriba a la derecha).
Se auto-monta (`UI.mount(el?)` crea `#rcv3` fijo z-index 60); fuente Press Start 2P (Google Fonts, fallback monospace) para titulos, texto en Trebuchet/system para legibilidad.

## API
- `showMenu()` (alias `showTitle`), `showTutorial()`->Promise (al terminar/saltar; guarda `rcv3_tut`), `showLobby({mode:'idle'|'host'|'join',code?})`, `lobbyUpdate({players,code,link,mode})`, `showRole(priv,role)`->Promise (priv.goal.text/points, priv.secret.text; secreto borroso hasta pulsar), `playCinematic(id,opts)`->Promise, `showFinal(result,state?)`, `showAchievements()`, `openSettings()`, `showCredits()`, `toast(msg,{bad,ms})`, `hide()` (cierra toda pantalla: llamar al empezar la partida), `isOpen()`, `settings()`, `unlock(ids)`, `achievements()`, utilidades `portrait(role,expr,px)`, `icon(name,px)`, `trophy(idx,px)`, `burst`, `confetti`.
- `playCinematic(id,opts)`: ids `'intro'` (usa `Story.intro` si es array >=3: strings u objetos `{text,who,still,fx[],dur,title}`; asigna still por palabras clave; anade plano de titulo final; si no, guion propio), `'rescate'`, `'derrota'` (1 plano; `opts.text`), o `opts.shots=[...]`. fx: `rain snow dust fog drip torch light lightning radio sway`. Espacio/Enter/clic avanza, Esc o boton Saltar termina. Respeta `Sound.speak` si narracion on.
- `showFinal(result)`: `{grade:'S'..'D',saved,score:{total,equipo,info,honestidad,riesgo},objectives:[{role,ok,text}],mvp:{role,why}|role,achievements:[id|{id}],stats:{..},verdict}` (si falta `score/achievements/stats` los lee de `state`). Guarda logros nuevos en `rcv3_ach` y marca NUEVO. Botones: emiten `restart {changeRole:false}`, `restart {changeRole:true}` (y abre lobby), `menu`.
- Eventos `UI.on`: `solo {difficulty}`, `host`, `join`, `role`, `ready`, `start {role,host,solo,difficulty}`, `restart`, `menu`, `settings {...ajustes}`, `tutorial {skipped}`. El lobby llama a `Net.host/join/setRole/leave/send('ready')` por si mismo y escucha `Net.on('players')`. Main solo debe reaccionar a `start`/`restart`/`menu`, llamar `UI.hide()` y `UI.showRole(priv,role)` antes de la partida.
- Ajustes (`rcv3_set`): dificultad (`facil|normal|everest`; `UI.settings().diff`), volumenes (llama `Sound.setVol('music'|'sfx'|'voice',v)`, `Sound.mute(b)`), narracion, tamano texto, reducir flashes (`.flash`), clave API (`rcv3_key`, `Story.setKey`). Logros: `Story.achievementsList()` (array de `{id,name,desc,secret?}` o `[id,name,desc]`), fallback con 14.
- Sfx usados: click hover back error select confirm toast typing round_start open drip rumble thunder radio_on radio_static intel share lie vote vote_pass vote_fail secret_reveal dice tick resolve_good resolve_bad achievement grade_s grade_low. Musica: menu tutorial briefing explore win lose.
- Assets opcionales (si faltan, fallback): `still_*` (valle cabina tormenta entrada radio mapa inundada rescate derrota), `portrait_<rol|lia>` (hoja de 4 expresiones neutral/preocupado/enfadado/feliz en columnas; se usa meta.fw/fh), `icons` (orden SPEC o `meta.names`), `trophies` (celda = indice de logro), `ui_frame` (marco 9-slice si existe), `player_*`, `lia`.
- Teclado: menu 1-7/flechas/W-S/Enter/D/M; tutorial flechas/Enter/Esc (E y 1-2-3 interactivos); lobby 1-2-3/Enter/Esc; final R/M.
